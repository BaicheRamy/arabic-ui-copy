# Saudi and Gulf profile

For products whose users are in Saudi Arabia and the Gulf. Run the checker with `--profile gulf`. Each row replaces the glossary row with the same concept; everything else in the skill stays the same.

| Concept | Use | Avoid | Note |
| --- | --- | --- | --- |
| Password | كلمة المرور | الباسورد / الرقم السري | Google, Microsoft, Tawakkalna and Tabby write كلمة المرور. كلمة السر is not flagged here either. |
| Phone number | رقم الجوال | رقم الموبايل | Zid, Tamara, stc and Tawakkalna write جوال. رقم الهاتف is fine for a field that accepts a landline. |

## Rules off

(none: Gulf readers use the house number and date formats)
