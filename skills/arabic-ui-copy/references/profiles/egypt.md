# Egypt profile

For products whose users are in Egypt. Run the checker with `--profile egypt`. Each row replaces the glossary row with the same concept.

- Numbers and months are the house ones: 1,234.5, and يناير، فبراير… (`Intl` for `ar-EG` prints Arabic-Indic digits unless you add `-u-nu-latn`).
- Currency: ج.م or جنيه.
