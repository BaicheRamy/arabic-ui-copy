# Maghreb profile (Algeria, Tunisia, Morocco)

For products whose users are in the Maghreb. Run the checker with `--profile maghreb`. Each row replaces the glossary row with the same concept.

- Numbers: decimal comma, as `Intl` formats `ar-DZ`, `ar-TN` and `ar-MA`: 1.234,5 and 2,5. Format with that locale and `-u-nu-latn`.
- Months: Algeria and Tunisia write جانفي، فيفري، مارس، أفريل، ماي، جوان، جويلية، أوت، سبتمبر، أكتوبر، نوفمبر، ديسمبر. Morocco writes يناير، فبراير، مارس، أبريل، ماي، يونيو، يوليوز، غشت، شتنبر، أكتوبر، نونبر، دجنبر.
- Currency: د.ج (Algeria), د.ت (Tunisia), د.م (Morocco).
